# GitHub upload checklist

Before making the repository public:

- [ ] Create the repository `SiDroForest-scale-aware-forest-composition`.
- [ ] Upload the **contents of this folder** (not the outer ZIP).
- [ ] Confirm that no large source rasters or private/local data were accidentally added.
- [ ] Check the repository URL in `CITATION.cff`; change it if you choose another repository name.
- [ ] Check whether MIT is the license you want / your institution permits.
- [ ] Add the new PANGAEA contextual-map DOI to `README.md` once assigned.
- [ ] Add the final manuscript DOI to `README.md` and `CITATION.cff` after acceptance.
- [ ] Create a GitHub release (e.g. `v1.0.0`) for the version used in the manuscript.
- [ ] Archive that release in Zenodo if you want a permanent software DOI.

The GeoTIFF datasets themselves should remain in PANGAEA rather than being duplicated in GitHub.
